# プライバシーポリシー

最終更新日：2026/11/1

nuts（以下「当方」）は、スマートフォンアプリ「パシャっと冷蔵庫＆レシピ」（以下「本アプリ」）における、ユーザーの情報の取り扱いについて、以下のとおり定めます。

## 1. 本アプリについて

本アプリは、冷蔵庫の中身を管理するためのアプリです。

- 食材を購入したら「追加」、使用したら「減少」させ、庫内の食材と消費期限を管理します。
- 庫内の食材に合わせて、AI（Google の Gemini）が夕飯のメニューを提案します。
- 食材の追加・使用の際、写真や画像に写った食材をまとめて増減できます（Gemini API を使用）。
- オリジナルレシピや、よく使うレシピの URL を登録できます。登録したレシピは一般には公開されず、身内や友人など、ユーザーが選んだ相手とだけ共有できます。

## 2. 取得・保存する情報

### 2-1. ユーザーが入力・登録する情報

- 食材名、数量、消費期限、使用の履歴
- レシピの内容（名前、材料、手順、メモ、画像、参考 URL、お気に入り・作った記録）

### 2-2. 写真・画像

- 食材の登録・使用のために、ユーザーが撮影した、またはギャラリーから選択した画像

### 2-3. レシピ共有のために必要な情報

- 共有したレシピの内容

### 2-4. 自動的に取得する情報

- 【端末情報、OS バージョン、クラッシュログなどを取得する場合はここに記載。取得しない場合は「自動的に取得する情報はありません」と記載】

当方は、氏名、住所、電話番号、位置情報、連絡先を取得しません。【メールアドレス等でログインする仕組みがある場合は、ここに追記してください】

## 3. 利用目的

取得した情報は、次の目的にのみ利用します。

- 食材・消費期限・レシピの管理機能を提供するため
- 写真に写った食材の認識、および夕飯メニューの提案を行うため
- レシピの共有機能を提供するため
- 不具合の調査や、本アプリの改善のため
- お問い合わせへの対応のため

広告配信や、ユーザーのプロファイリングには利用しません。

## 4. 情報の保存場所

- 食材・レシピなどのデータは、基本的にご利用の端末内に保存されます。
- レシピを共有する場合に限り、共有対象のデータが【サーバー名（例：Vercel／Firebase など）】に保存されます。
- 【バックアップ機能がある場合は、保存先と内容をここに記載】

## 5. AI（Gemini）の利用について

本アプリは、Google が提供する生成 AI「Gemini」の API を利用しています。ご利用前に、以下の点をご確認ください。

### 5-1. Gemini に送信される情報

- 食材認識のために選択・撮影された画像
- 夕飯の提案のために必要な、庫内の食材名・消費期限などのテキスト情報

これらの情報は、本アプリの機能を使ったときにのみ、当方の中継サーバー（【Vercel】）を経由して Gemini API に送信されます。当方の中継サーバーは【送信内容を保存しません／○日間ログとして保持します】。

### 5-2. Google での取り扱い

送信された情報は、Google の Gemini API 利用規約に従って取り扱われます。ご利用のプランによっては、送信された画像やテキストが Google のサービス改善に利用されたり、品質向上のために担当者が内容を確認したりする場合があります。当方は、ユーザーの情報を AI の学習目的で独自に利用することはありません。

### 5-3. 撮影・送信時のご注意

次のものが写り込んだ画像は、送信しないでください。

- 人の顔や体
- 氏名、住所、電話番号、クレジットカード番号などが分かる書類やレシート、宛名ラベル
- その他、第三者に知られたくない情報

冷蔵庫の周辺や室内が写り込む場合がありますので、撮影範囲にご注意ください。

### 5-4. AI の出力について

- AI による食材の認識や、消費期限・メニューの提案には、誤りが含まれる場合があります。
- 食材の識別が間違っていることがありますので、登録された内容は必ずご自身でご確認ください。
- アレルギーのある食材や、食品の安全性・消費期限の最終判断は、必ずご自身で行ってください。AI の提案による結果について、当方は責任を負いかねます。

| 【Vercel】 | Vercel Inc. | AI 機能の中継サーバー |

各サービスにおける情報の取り扱いは、それぞれの提供元のプライバシーポリシー・利用規約に従います。

## 7. 第三者への提供

当方は、次の場合を除き、ユーザーの情報を第三者に提供しません。

- ユーザーご本人の同意がある場合
- 本アプリの機能の提供に必要な範囲で、上記の外部サービスに送信する場合
- 法令に基づく場合

## 8. レシピの共有について

- レシピは、一般には公開されません。ユーザーが選んだ相手にのみ共有されます。
- 共有できるレシピは【10件】までです。
- 共有した相手は、共有されたレシピの内容を閲覧できます。共有する相手と内容は、ご自身の責任でお選びください。
- 他人の著作物（書籍・サイトの文章や写真など）を共有する場合は、権利を侵害しないようご注意ください。

## 9. カンパ（任意の支援）について

【レシピの共有が10件を超える場合のお願いなど、実際の運用に合わせて記載。決済方法、決済情報の取り扱い（例：当方では決済情報を保持しない）も記載】

## 10. 端末の機能へのアクセス許可

本アプリは、次の機能の利用許可を求める場合があります。

- カメラ：食材を撮影するため
- 写真・メディア：ギャラリーの画像を選択するため
- 【通知：消費期限をお知らせする場合】

許可はいつでも端末の設定から変更できます。許可しない場合でも、該当しない機能は利用できます。

## 11. 保存期間・削除

- 端末内のデータは、ユーザー自身が削除するか、アプリをアンインストールすると削除されます。
- サーバーに保存された共有データは、【ユーザーが共有を解除した時／削除を依頼された時】に削除します。
- 削除をご希望の場合は、下記のお問い合わせ先までご連絡ください。

## 12. 安全管理

通信は暗号化（HTTPS）して行い、情報の漏えい・滅失を防ぐよう、適切な管理に努めます。

## 13. 国外での処理

Google などの外部サービスは、日本国外のサーバーで情報を処理する場合があります。

## 14. お子様の利用について

本アプリは、お子様のみでの利用を想定していません。未成年の方は、保護者の方の同意のうえでご利用ください。

## 15. ポリシーの変更

本ポリシーは、必要に応じて改定することがあります。重要な変更がある場合は、アプリ内または本ページでお知らせします。
